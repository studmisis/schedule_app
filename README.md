# Schedule App

Веб-приложение с разделением на клиентскую и серверную части.

## Структура проекта

```
schedule_app/
│
├── client/   # React + Vite
│
└── server/   # Node.js + Express
```

## Запуск проекта

Проект состоит из двух частей, которые запускаются отдельно.

---

## Server

Перейти в папку сервера:

```bash
cd server
```

Установить зависимости (первый запуск):

```bash
npm install
```

Запустить сервер:

```bash
npm run dev
```

Если всё успешно, в терминале появится:

```
Сервер запущен на порте 3000
```

Сервер работает по адресу:

```
http://localhost:3000
```

Проверка работы сервера:

```
http://localhost:3000/api/test
```

При открытии адреса должен вернуться ответ:

```json
{
  "message": "Сервер отвечает"
}
```

Если ответ получен — сервер успешно запущен и готов принимать запросы.

---

## Client

Открыть второй терминал.

Перейти в папку клиента:

```bash
cd client
```

Установить зависимости (первый запуск):

```bash
npm install
```

Запустить клиент:

```bash
npm run dev
```

Приложение будет доступно:

```
http://localhost:5173
```

После открытия страницы в браузере должен отображаться ответ сервера:

```
Сервер отвечает
```

Клиент успешно подключился к серверу и обмен данными между React и Express работает.
